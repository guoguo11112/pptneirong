课程一

《不原谅也没关系》× 艺术疗愈

心理疗愈主题 · 体系化课程内容（延伸补充）

内容简介

围绕皮特·沃克《不原谅也没关系》（CPTSD 疗愈）展开，将心理学理论、认知重构与艺术疗愈体验相结合，帮助学习者理解童年与关系创伤的深层影响，并给出可操作的自我疗愈路径与体验式练习。

设计逻辑

内容按“认知科普 → 打破羞耻 → 认知重构 → 方法体系 → 体验落地 → 行动引导”递进编排：先建立对创伤普遍性与影响机制的认知，再拆解毒性内在批判与 4F 反应，进而对“原谅”做心理松绑，最后落到身体 / 心理情感 / 社群 / 自然四类疗愈方法与艺术疗愈体验，并在结尾预留互动与领取钩子。

参考学派 / 理论

  • 复杂性创伤后应激障碍（CPTSD）— 皮特·沃克《不原谅也没关系》
  • 内在家庭系统（IFS）
  • 4F 应激反应模型（战 / 逃 / 僵 / 讨好）
  • 表达性艺术治疗（Expressive Arts Therapy）与艺术疗愈发展史（Margaret Naumburg、Adrian Hill、AATA）
  • 内在小孩疗愈
  • 依恋理论、心理动力学与 CBT 视角

课程二

科学正念：从日常焦虑到安稳睡眠

情绪—睡眠自我调节系统 · 体系化课程内容（延伸补充）

内容简介

从情绪的生理机制讲起，串联正念、EFT、ACT 等实操方法，再延伸到失眠的科学干预（CBT-i），构建一套“情绪调节 + 睡眠改善”的自我调理系统。

设计逻辑

内容按“机制科普 → 澄清误区 → 正念方法与态度 → 疗法体系 → 科学干预 → 平衡与行动引导”编排：先讲清情绪与生理的关联并纠正常见误解，再引入正念练习与 7 大态度，叠加 EFT / ACT / STOP 三类可操作疗法，最后聚焦失眠的 CBT-i 干预与睡眠卫生，收束到生活平衡。

参考学派 / 理论

  • 正念减压（MBSR · Jon Kabat-Zinn）与正念认知疗法（MBCT）
  • 自主神经系统理论（交感 / 副交感）
  • EFT 情绪释放法（能量心理学 / 中医经络）
  • 接纳承诺疗法（ACT · 第三代 CBT）与心理灵活性六边形模型
  • 失眠认知行为疗法（CBT-i）与 Spielman 3P 模型
  • 矛盾意向法（Paradoxical Intention）、睡眠卫生
